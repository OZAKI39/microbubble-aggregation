> **补充（同日稍后，`evidence/burst_2_3MHz_20261108/`）：** 下文的"爆裂"更准确地说是：主团不停甩出单个、多为较小的泡（64 泡 2 s 内主团留下 91–94%），同时内部剧烈翻动；原因是 2–3.3 MHz 正在这些泡的共振附近，泡团内部的力强而不均匀，硬球接触顶不住拉开，弱粘附又太小。

**用户决定（2026-11-08）：**
1. **粘附：** 可以降低，不应因为粘附挡住对形状演变的研究；所有运行统一用同一种粘附，与声压无关，数值从一个随机范围里取；预训练用的参数要和测试验证过有效的参数在同一范围内。
2. **泡团大小：** 预训练泡团取 64–255 个泡。
3. **动作，两种都做：**
   - "不改动作设计"：指令与位置无关，初态保持随机，离中心的声场照样利用，用于生成预训练数据；
   - "按位置设计动作"：按泡团所在位置的实际声场设计指令，只用于检验真实实验和仿真的匹配程度。
4. **计划在硬球接触里加入布朗运动**（这次只出方案，见本任务的汇报）。

## 结论

**一、代码已按决定改好；6–10 MHz 下新范围验证通过；2–3.3 MHz 下没有通过：泡团会爆裂，1 ms 步长远远不够。**

| 范围 | 验证结果 |
|---|---|
| 粘附 1e-14–1e-12 N，6.0 / 9.375 MHz，64 / 128 / 255 泡 | ✓ 压向节点面的程度是无粘附时的 0.52–1.20（判据 ≥ 0.5） |
| 同上，1 ms 步长 | ✓ 图样运行（5.85–9.46 MHz）每步最大位移 ≤ 0.08 µm，没有一步超过 0.1R；成形测试 ≤ 0.42 µm |
| 粘附 1e-14–1e-12 N，2.8–3.4 MHz，64–255 泡 | ✗ 泡团裂成 3–13 块，泡被甩出最远约 4 mm；1 ms 一步内泡最多移动约 4R |
| 同上，步长 1 / 0.5 / 0.25 / 0.1 ms | ✗ 0.1 ms 时仍有 1.7–3.3% 的步超过 0.1R；0.25 ms 和 0.1 ms 的泡团中心仍差 5–8 µm（远大于一个像素 0.6 µm）。块数（4–6）倒是各步长一致 |

**二、2–3 MHz 下"弱到不挡住成形"和"不爆裂"互相矛盾，单一个粘附范围满足不了两者。** 同一个 64 泡初态，随机动作 2.82 MHz，1 ms：

| 粘附 | 超过 0.1R 的步 | 一步最大位移 | 末了块数 |
|---|---|---|---|
| 1e-14 N | 35% | 3.8R | 4 |
| 1e-12 N | 35% | 3.8R | 4 |
| 1e-11 N | 4.7% | 2.8R | 1 |
| 1e-10 N | 0.55% | 0.31R | 1 |
| 5.04e-10 N（录像标定值） | 0.70% | 0.31R | 1 |

- **6–10 MHz 下：** 1e-11 N 起就挡住成形。
- **2–3 MHz 下：** 要到 1e-10 N 泡团才不爆裂、1 ms 才够用。
- **两个区间不重叠。** 按"粘附与声场无关、所有运行同一个范围"的决定，无法同时满足"预训练参数在验证范围内"。需要用户决定（见汇报）。
- **另一个线索：** 录像里 2.5 MHz 的泡团很少分裂，团速 120–250 px/s；模型在弱粘附下爆裂，泡以约 mm/s 的速度被甩出。这说明，如果真实粘附确实很弱，那么模型在 2–3 MHz 的泡间力可能偏强。这里没有验证。

**三、两种图样动作都能用（普通预训练运行，配置里只有种子和时长）：**

| 运行 | 类型 | 泡数 | 频率 | 粘附（抽到的） | 离参考点 | 泡处 \|p\| / 局部最大（中位） | 长宽比 | 块数 |
|---|---|---|---|---|---|---|---|---|
| LOCAL 状态 203 / 动作 1 | `pattern_local`（按泡团位置） | 125 | 7.28 MHz | 6.9e-14 N | 0（参考点即泡团中心） | 0.06 | 1.08 → 2.45 | 1 |
| 状态 203 / 动作 1 | `pattern`（按通道中心） | 125 | 7.28 MHz | 6.9e-14 N | 2.1 mm | 0.16 | 1.08 → 2.07 | 1 |
| 状态 204 / 动作 11 | `pattern` | 206 | 9.46 MHz | 3.2e-13 N | 7.4 mm | 0.23 | 1.20 → 1.90 | 1 |
| 状态 202 / 动作 3 | `pattern` | 99 | 5.85 MHz | 1.4e-13 N | 10.9 mm | 0.21（0.63 → 0.07） | 1.06 → 1.66 | 1 |
| 状态 201 / 动作 28 | `pattern` | 121 | 3.25 MHz | 1.1e-14 N | 1.4 mm | 0.30 | 爆裂（最大 59） | 最多 13 |

- **按通道中心设计时，指令与泡团位置无关：** 离中心几毫米的泡团照样被推到低声压处，并沿低压带拉长（`fig3_demo_runs.png`、动画）。
- **同一初态、同一动作种子，两种设计对比（状态 203）：** 按泡团位置设计时泡团正好坐在零线上（0.06），按通道中心设计时在离零线稍远的低压带里（0.16）。两者都沿斜线拉长。
- **3.25 MHz 的那条就是上面说的爆裂。**
