# 泡的大小分布（2026-11-07，用户同意的实施方案）

> **状态（2026-11-09 核对）：** 现行。

**改了什么：** 以前所有泡都是 1.78 µm，现在每个泡有自己的半径。

- **半径的分布：** 对数正态，中位 1.78 µm。几何标准差（下称 σ_g，越大泡的大小越分散）每条运行在 1.0–1.5 之间随机抽取，截断在 0.8–3.0 µm。
- **包膜参数随半径变：** 按 Tu et al. 2009 的 SonoVue 数据（大泡的包膜更硬、更粘），线经过原来 1.78 µm 的参数。
- **近场公式不改：** F2 的近场、粘附和接触都改用两泡半径之和；阻力按各泡自己的半径；近距离润滑改用不等大球的公式。

所有泡一样大时，整条运行与以前**逐位相同**。

**检验结果：泡大小不一，也没有让泡团松开。**

- **默认粘附下，内部完全不重排。** 6 个起始团（σ_g = 1.5，泡的大小最分散的一档）在开头 0.1 s 后一对接触也不再断开，与所有泡一样大时相同。泡团被压得更紧：每泡接触数 2.2–2.6 → 2.6–3.0。
- **F2 的约束减弱了，但不起作用。** 各泡之间 F2 力差与推动整团之力的比值从 37–75 降到 10–35，可泡团照样不动。默认粘附下，现在卡住泡团的是粘附。
- **20 泡、32 泡的团掉了几个单泡。** 开头 10 ms 内有 1–3 个半径 1.4–2.3 µm 的单泡离开，被推到 0.6–4.4 mm 外；团本身不变。
- **不加粘附时，有的更碎，有的更整。**
  - 122 泡的团以前单靠 F2 不散（最后最大块 96%），现在会碎（68%）；
  - 20 泡、32 泡的反而比以前完整（90% 对 55%，47% 对 38%）；
  - 99 泡的仍不散。

按用户的原则，这两处物理修正（大小分布、近场核对）做完后泡团仍卡死，说明原因在别处，不再在这两处硬调。

## 验证

**测试：** 服务器 52/52 通过；笔记本 51/52 通过。笔记本上失败的一项仍是已知的 AVX-512 末位差：存下的单层泡团文件是服务器生成的，笔记本重新生成时差 1.2e-20 m，与本次无关。

新增或改写的检查：

- 不等大球的润滑系数：等大时正好等于原来的常数（0.5、0.45、3/56）；两泡交换顺序结果相同。
- 编译接触步与 Python 接触步一致：σ_g = 1.5 的真实初态被粘附压紧，以及三个大小不同、几乎相贴的泡，位置差 ≤ 1e-18 m，各项判定相同。
- F2：NumPy 版、逐对参照版、带延迟的编译版在大小不同的泡上互相一致。
- 粘附：在不等大泡上，接触点在两泡半径之和处。
- 初态：100 个种子，半径都在范围内、无重叠、离壁 ≥ 50 µm，并能按记录重新长出同一个团。
- APECSS：混在一起的大小泡，每个都与它单独时的响应逐位相同。

**所有泡一样大时与以前逐位相同：**

- 笔记本上，10 个种子的初态与改动前的代码逐位相同。服务器上生成的文件与笔记本有上面那种末位差。
- 服务器上用新代码、`"radius_sigma_g": 1` 重跑驻波检验的两条运行（20 泡、122 泡，各 1.5 s）。每 1 ms 存下的 1501 帧位置与改动前的运行逐位相同，最大差 0 m（`data/SIGMA1_CHECK.json`）。

几点说明：

- 形状变化的指标同 soft3d（俯视长宽比每 0.1 s 的变化），每个泡按自己的半径画圆盘。
- 20、32 泡有粘附时最大块不到 100%，是开头 10 ms 内离开的那几个单泡。
- “同一包膜”是对照：按 f2 核对的静态估计，这种情形互相排斥的泡对最多（11–37%），而按 Tu 2009 包膜随半径时只有 0–7.5%。即使是它，有粘附时泡团也不重排。

## 局限

- 只检验了一种驱动（X− 单路，6000 Pa-eq，2.5 MHz）、一种 σ_g（1.5）、每条 1.5 s。
- 包膜参数随半径的关系，是从 Tu 2009 图 4 读图拟合的（约 ±10%）。半径下限 0.8 µm 以下没有数据。
- 粘附力仍是唯象的定值。它当初是用所有泡一样大的泡团、对照真实录像标定的，泡大小不一以后没有重新标定。
