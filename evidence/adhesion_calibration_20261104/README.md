# 唯象粘附力的标定（2026-11-04）

**目的：** 预训练档用全体耦合时，团太软：每移动 1 px 的形状变化约为真实的 40 倍，而且会碎开（见分支 `pretrain-softness-check` 的 `visualization/ab_protocol_sim/`）。检验加入 `microbubble.forces.adhesion_forces`（唯象短程粘附，默认关闭）能否让团的“软硬”接近真实 A/B，并定出强度范围。

指标与 `visualization/ab_protocol_figures.py` 完全相同（直接调用其函数）：按 0.6 µm/px 画成像素，看每 0.1 s 窗口内团的形状变化、是否分裂、长宽比。真实参照为 MB_track A/B 开 PZT 时的团。

`EXPLORATORY / PHYSICS_UNCALIBRATED / PRETRAIN_TIER / PHENOMENOLOGICAL_ADHESION / training_ready=false`；像素尺度 0.6 µm/px 为暂定值。

## 运行

- **共同设置：** AG32_local（32 泡）；全体耦合，带传播延迟（现默认）；直接声场；响应表；只开 X− 一路 1.5 s（你的实验式方案的第一段）。粘附作用距离 0.2 µm。
- **第 1 组 `SWEEP_1P5.json`：** 从登记的方阵初态出发，2000 Pa-eq，粘附 0 / 3e-12 / 1e-11 / 3e-11 / 1e-10 / 3e-10 N，中心和偏心各一，共 12 条，全部 PASS。
- **第 2 组 `ROUND2000.json`：** 从“已收圆的团”出发（分支里成对模型运行 0.25 s 时的位置，`round_initial_*.npy`，平移回原中心），2000 Pa-eq，粘附 0 / 3e-11 / 1e-10 N，中心。
- **第 3 组 `G5000.json`：** 同样从圆团出发，5000 Pa-eq（仅用于验证，临时把声源上限提到 5000），粘附按 (5000/2000)² 放大，相当于 2000 Pa-eq 下的 0 / 3e-11 / 1e-10 N。中心和偏心各一；偏心不加粘附的那条为省时间没跑。

**为什么提高驱动：** 除粘附外，所有力都与声源强度的平方成正比，所以“粘附 F、驱动 A”与“粘附 F·(A′/A)²、驱动 A′”走出同一条轨迹，只是快慢不同。2000 Pa-eq 下粘住的团只走约 9 px/s，0.1 s 窗口里不到 1 px，“每 px 形状变化”测不出来；提到 5000 Pa-eq 后团速 56–59 px/s，与真实开启时的团速（7–265 px/s，因 PZT 而异）同一量级。

## 结果

| 情形 | 每 px 形状变化（中位） | 分裂窗口占比 | 长宽比（中位） | 团速 px/s |
|---|---|---|---|---|
| 真实 A/B，开 PZT | 0.0018 | 很少（追踪在分裂处切断） | 1.12 | 7–265 |
| 成对模型（分支运行，同一段） | 0.00015–0.00019 | 0 | 1.10–1.15 | 约 330 |
| 全体，无粘附，方阵初态 | 0.063–0.079 | 48–65% | 1.66–1.69 | 19–31 |
| 全体 + 粘附 ≥ 3e-11 N，方阵初态 | 0.004–0.009 | 0 | 1.7–2.3 | 10–13 |
| 全体，无粘附，圆团初态，2000 / 5000 Pa-eq | 0.10 / 0.013（窗口很少） | 79% / 88% | 1.78 / 1.53 | 32 / 258 |
| 全体 + 粘附，圆团初态，2000 Pa-eq | 测不出（走太慢） | 0 | 1.16 | 9 |
| **全体 + 粘附，圆团初态，5000 Pa-eq** | **0.0022–0.0048** | **0** | **1.31–1.45** | **56–59** |

1. **不加粘附，团在全体耦合下总会碎**，从方阵出发或从圆团出发都一样。
2. **粘附 ≥ 3e-11 N（以 2000 Pa-eq 计）就不再分裂。** 3e-12 N 不起作用，1e-11 N 是过渡区。
3. **从方阵初态出发时，团在开始约 0.25 s 内被拉成长条（长宽比 2.0–2.3）后被粘住定型。** 从已收圆的团出发则没有这个问题，因此这是初态造成的，不是粘附力本身的问题。登记的初态（方阵留 0.71 µm 缝）不适合带粘附的运行。
4. **圆团 + 粘附、驱动到真实团速量级时，每 px 形状变化为 0.0022–0.0048，与真实的 0.0018 只差 1.2–2.7 倍**（原来差约 40 倍）。每 0.1 s 的形状变化 0.013–0.026，与真实开启后 1 s 内的 0.026 相当。粘附从 3e-11 增到 1e-10 N（以 2000 Pa-eq 计）时变化不大。
5. **定出的范围：** F_adh ≈ (3e-11 – 1e-10 N) × (A / 2000 Pa-eq)²，即 F_adh / A² ≈ 7.5e-18 – 2.5e-17 N/(Pa-eq)²，A 为每路声源强度。按你从团速推出的全体耦合增益 4600–6500 Pa-eq 换算，F_adh ≈ 1.6e-10 – 1.1e-9 N。这与 Kokhuis 等 2013 测得的靶向微泡与表面的结合力（0.9–2 nN，特异性结合）同一量级。泡与泡之间非特异性粘附的测量值没有找到。

## 仍然不符或未检验

- **团在持续推动下慢慢变长：** 长宽比在 1.5 s 内从 1.1–1.15 升到 1.3–1.5；真实中位 1.12，p90 1.30。粘附只管“拉住”，不阻止泡沿彼此表面滑动；可能还缺切向摩擦（滚动 / 滑动阻力），或真实团贴壁受阻。
- **团速的时间过程：** 真实团开启后快速移动 0.3–1 s 就慢下来，仿真没有壁，一直匀速。
- **只检验了：** X− 单路一段；AG32 一种大小（真实团面积约 3 倍）；线性区附近的声压；未做随机多路动作和换方向。
- **初态：** 登记的初态都是留缝的规则排列。带粘附的预训练运行需要“已形成的团”作初态。本次用成对模型运行收拢后的位置，这只是权宜做法。

## 之后（同日）

用户接受后，粘附已按比值默认开启（k = 1.4e-17 N/(Pa-eq)²，取上面范围的几何中值），并新增了已成形团初态。在紧密排列的已成形团上，“长宽比在持续推动下变长”的问题消失了；经检验不需要滑动阻力，这项代码没有并入仓库。见 `evidence/pretrain_formed_defaults_20261104/`。
