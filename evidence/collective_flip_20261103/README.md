# 全体耦合下泡团反向漂移的核查（2026-11-03）

**现象：** 在“全体耦合”（`coupling: "collective"`）下，紧密泡团的主 Bjerknes 合力指向声压弱处；用两两耦合或孤立泡计算，则指向声压强处。用响应表和用方法 A 结果相同，所以这是耦合模型本身的行为。本核查只做诊断，不改任何工程代码。所用脚本合在 `SCRIPTS.txt`，运行时 `PYTHONPATH` 指向本工程。

## 结论

1. **模型行为确认**（`COMPARE_CONTROLS.json`、图 a）。
   - 设置：AG32_local，X 对 3000 Pa-eq，2.5 MHz，直接声场，响应表，运行 20 ms，泡团中心离声压最强处（x = 0）20 或 75 µm。配置见 `configs/`。
   - 两两耦合：泡团中心朝 x = 0 移动 7.2 µm 和 21.2 µm。
   - 全体耦合：朝反方向移动 1.0 µm 和 2.4 µm。
   - 两种情况下泡团都保持紧密（相邻泡平均间距都缩到约 2.0R）。

2. **物理上说得通，对紧密泡团可信，大小只是粗估**（`FLIP_MAP.json`）。
   - 单泡的固有频率约 3.04 MHz，高于 2.5 MHz，属于“驱动低于固有频率”的情形，被推向声压强处。这是单泡的公认规律。
   - 泡团整体的固有频率随泡数增多、间距缩小而降低。用同一线性响应估计，32 泡紧密团约为 0.94–1.14 MHz；只有 2 个泡时，几乎相切才会反向。
   - 整团固有频率低于驱动频率后，泡团整体像一个“大泡”，被推向声压弱处。
   - 文献依据：d'Agostino & Brennen (JFM 1989) 指出泡云参数 N·R/团半径 ≫ 1 时整团以更低频率振动；本例约为 6。
   - 没有找到微泡团反向漂移的直接实验测量。
   - 点源模型在泡几乎相切时比较粗糙，所以力的大小（约为两两耦合的 −0.1 倍）只是粗估。

3. **问题：泡间传播延迟被忽略，泡散开时结果不可靠**（`FLIP_RETARDED.json`、图 b）。
   - 代码里的耦合 K = ρω²/(4πd) 假定声波瞬时到达，只在 kd ≪ 1 时成立（2.5 MHz 波长 0.6 mm）。
   - 诊断时补上 e^(−ikd)（仅在本诊断中，工程代码未改）：
     - 紧密状态几乎不变：AG32_local −0.108 → −0.104，N64_compact −0.071 → −0.068；
     - 散开状态变化很大：N64_loose −0.33 → +0.30，AG32_ring −0.24 → +0.55，N200_wide −15.4 → −0.12。
   - 两两泡间力用的是同一近场形式；远处的力本来就弱，受的影响较小，但同样未计延迟。
   - 补延迟属于改物理方程。已经用 APECSS 自带的“准声学”多泡相互作用（声压以声速传播）作为独立参照核对过，见第 5 点。用户于 2026-11-03 接受后已并入预训练档，默认开启；`configs/pretrain_policy.json` 中为 `propagation_delay`，运行配置可以关闭。

4. **现有实验视频不能定论**（`SIZE_DIRECTION.json`，只读 MB_track 的 expA/expB 跟踪结果）。
   - 同一 PZT 时段内，大团和 200 px 内小目标的运动方向大多相同。在有驱动的时段共 8 对，其中 7 对余弦为 0.59–1.0；1 对为 −1.0，但这一对速度很小。
   - 但这批数据没有声场分布，表里也没有像素尺寸，而且大多是单个 PZT 在推（行波为主，按理本来就不会反向）。
   - 能定论的实验：用相对的一对 PZT 开驻波。小泡会排成间隔约 0.3 mm 的条带，看大团是停在条带上，还是停在两条带之间。

5. **用 APECSS 自带的多泡相互作用核对补延迟的公式**（用户选择先核对再决定；`QA_CHECK_*.json`、`delay_check_apecss.png`、脚本见 `APECSS_CHECK_SCRIPTS.txt`）。
   - **设置：**
     - 冻结工况的泡（RPAR + Marmottant，ODE 1e-10），2.5 MHz，各泡受均匀 1000 Pa（线性区），位置固定。
     - APECSS 每 T/512 更新一次相互作用，跑 60 个周期，取最后一个周期的基频。
     - 两种相互作用：IC（瞬时、不可压）和 QA（准声学，各泡发出的声波以声速传播）。
   - **比较对象：** 我们的公式 u = (I + χK)⁻¹χP，χ 取同一 APECSS 单泡的结果，K 分为不带相位（与代码相同）和带 e^(−ikd) 两种。
   - **误差：** max_i |V1_i − u_i| / max_i |V1_i|。

   | 情况 | 带延迟 vs QA | 代码现状 vs QA | 代码现状 vs IC |
   | --- | --- | --- | --- |
   | 2 泡，kd 0.5–3（48–290 µm） | 0.002–0.04% | 2–3% | 0.006–0.04% |
   | 16 泡圆环，半径 150 µm（kd 至 3.1） | 0.07% | 42% | 0.25% |
   | N64_loose_r0 中随机 16 泡（kd 至 2.3） | 0.57% | 62% | 0.9% |
   | AG32_ring，32 泡（kd 至 3.1） | 0.12% | 109% | 0.84% |
   | AG32_local，32 泡紧密团（kd 至 0.2） | 14% | 10% | 8% |

   **结论：**
   - 现有代码与 APECSS 的瞬时模型一致，按设计工作，只是缺了传播延迟。
   - 泡散开时，补上 e^(−ikd) 后与 APECSS 的独立计算吻合到 0.6% 以内；不补则偏差 40–110%。
   - 泡几乎相切时（kd ≤ 0.1），QA 本身不准：改相互作用的时间分段，结果就变 1–2%，所以那里的差别不能用来判断补法。同时这个距离上延迟的影响本来就小，三种结果都主要受近场和分段计算影响。

   **未运行：** N64_loose_r0 全部 64 泡。QA 的耗时增长远快于泡数，32 泡圆环已用 72 分钟，所以停掉，改用其中 16 泡。AG32_ring 一行取自完整运行打印的摘要（3 位有效数字）。
