## 结论

**一、功能已经加进项目代码，普通的预训练运行就会用到它。** 运行配置不用改：
- 按 `action_seed`，一半的运行自动成为"图样运行"；配置里写 `"action_kind": "random"` 或 `"pattern"` 可以指定。
- 图样运行在起始泡团定下来以后，按四枚圆片在泡团中心的声压和梯度算出四路幅相：
  - 第一段让驻波零线或零点正好穿过泡团中心；
  - 之后零线方向、两对的节点位置、线与点之间随机、平滑地变化（随机节点间隔 1–6 s，中间线性变化，每段 0.1 s，最多 64 段）。
- 整条运行一个频率（3–10 MHz 随机），最大一路为 6000 Pa-eq。
- 配置没写粘附时，用弱粘附（1e-14–1e-12 N 对数均匀随机）。
- 随机动作那一半与以前逐位相同（图样的抽签用单独的随机流）。

**二、四条普通预训练运行（配置里只有两个种子和 6.4 s）都跑完了，泡团跟着声场变：**

| 运行 | 泡数 | 频率 | 弱粘附 | 起始位置 x | 零线质量 | 泡团中心到零集（中位 / 最大） | 1R 内的份额（中位） | 块数 |
|---|---|---|---|---|---|---|---|---|
| 状态 201 / 动作 28 | 49 | 3.25 MHz | 1.4e-13 N | 1.4 mm | 这条全程是点，没有线 | 4.2 / 12.6 µm | 0.06 | 最多 2 |
| 状态 202 / 动作 3 | 37 | 5.85 MHz | 4.8e-14 N | 10.9 mm | 0.12（差） | 1.2 / 3.7 µm | 0.43 | 1 |
| 状态 203 / 动作 1 | 51 | 7.28 MHz | 1.0e-13 N | −2.0 mm | 0.016（好） | 1.6 / 3.2 µm | 0.45 | 1 |
| 状态 204 / 动作 11 | 99 | 9.46 MHz | 7.0e-13 N | −7.4 mm | 0.12（差） | 6.0 / 13.7 µm | 0.15 | 1 |

- **零线质量**：预测的零线上、离零点 20 µm 内，圆片声场本身的 |p| 与这片区域最大 |p| 之比；0 表示声场真有这条零线。
- **最好的例子是状态 203**（离通道中心 2 mm，零线准确）：泡团沿零线拉长，并跟着零线转（`fig1_pattern_runs.png`、动画）。这就是这次要的"平滑的形状变化"出现在普通预训练数据里。

**三、两个需要知道的局限：**
- **只在通道中心附近有准确的零线（`fig2_line_quality.png`）。** 离中心远（沿 x）时，侧面一对 PZT 的声波斜着到达，两对之间的相位在泡团范围内就变了，准确的零线不存在，只剩一道低声压的谷。这是四枚圆片这种布置本身的限制，换相位也消不掉。按现在的随机初态（泡团中心沿 x 分布到 16 mm），200 个初态里：

| 离中心 \|x\| | 初态份额 | 零线质量中位数（3.5 / 6.5 / 9.5 MHz） |
|---|---|---|
| 0–4 mm | 19% | 0.05 / 0.03 / 0.03，准确 |
| 4–8 mm | 26% | 0.11 / 0.15 / 0.19 |
| 8–16 mm | 55% | 0.19 / 0.27 / 0.33，只是谷 |

  所以现在的图样运行里，只有约两成有准确的零线。
- **弱粘附只给了图样运行，于是弱粘附与 3–10 MHz 绑在一起，**而随机动作那一半（2–3 MHz）仍是默认的 5.04e-10 N。世界模型如果不知道每条运行的粘附值，可能把"动得开"错归于频率。粘附值每条运行都记在 `task.adhesion_force_N`。

**四、第一版的节点移动太快，已改（`fig3_first_version_quarter_wavelength.png`）。**
- **第一版：** 节点偏移上限是四分之一波长（10–3 MHz 时 37–125 µm）。节点典型移动速度 8–23 µm/s，四条运行里零集大多直接跑离泡团：泡团中心离零集中位 6–31 µm、最多 117 µm，1R 内份额中位 0.00–0.08。
- **原因：** 上一步量过，一张片跟得上移动的节点面只到约 3 µm/s（0.8 µm/s 完全跟上，12.5 µm/s 跟不上）。
- **改法：** 偏移上限改为 ±16 µm，节点典型速度约 3 µm/s，正好在"跟得上 / 跟不上"的分界上。
- **零线转动的速度没改：** 典型约 17°/s，在片的分界 14°/s 附近，两种情况都有。
- 同样的种子改后重跑，结果就是上面的表。

**图样族（`control.pattern_actions` 的文档字符串）：** 在起始中心 c 附近，用局部平面波形式
p = −[cos a · sin(κx(x − cx − sx)) + (κx/κy) · sin a · e^{iφ} · sin(κy(y − cy − sy))]，零点处的声压梯度大小对任何 a、φ 都相同（推力大小不变）。
- **a**（−90° 到 90°）：φ = 0 时零线方向为 a + 90°，覆盖所有方向；
- **sx、sy**（±16 µm）：移动两对的节点，节点偏开时穿过泡团的零线会弯；
- **φ**：0 为线，大于 0 时只剩点（三维里是竖线）；
- **路径：** 各随机节点上，a 均匀；sx、sy 均匀（起点为 0）；φ 以 0.5 / 0.25 / 0.25 的概率取 0 / 90° / 两者之间均匀。所以准确的零线大约占四分之一的时间：只有相邻两个节点都是"线"时，中间才一直是线；其余时间只有点是零，φ 小时沿原来的线留下一道近乎为零的谷。

## 实际验证了什么

- **本地测试：** 55 通过，1 未通过。未通过的是已知的 AVX-512 末位差（`test_irregular_clusters_are_connected_disordered_and_never_overwritten`，相对差 1.3e-14），与这次改动无关，以前就是这样。
- **服务器测试：** 56/56 通过（改动后的两个版本各跑一次）。
- **新测试：**
  1. 图样运行的份额、频率和粘附的分布符合策略，同一种子同一结果；
  2. 用平面波圆片模型，每一段在其节点处的声压为 0（< 1e-9）、梯度大小全程相同（相对差 < 1e-9），最大一路恰好是上限；
  3. 一条真实的小运行：种子 1 抽成图样运行，弱粘附、频率与抽签一致，第一段在起始泡团中心的圆片声场里为 0（< 1e-9）；同一配置写 `action_kind: random` 时得到这个种子的随机动作和默认粘附。
- **四条普通预训练运行：** 都是 PASS（每条 129–142 s，RTX 4090）。
- **零线质量普查：** 200 个随机初态 × 3 个频率。

## 局限

- 准确的零线只在通道中心沿 x 约 4 mm 以内（初态的约两成）。
- 弱粘附只在图样运行里，和频率段绑在一起。
- 3–4 MHz、弱粘附下有快速事件，每步位移可达约 1R（`evidence/morph_sheet_20261108/`）；状态 201（3.25 MHz）的泡团一度分成 2 块。
- 节点间隔、偏移上限、线/点权重是按一张 250 泡片测出的跟随速度选的；预训练里的泡团是 16–128 泡的三维团，跟随速度可能不同。
- 四条运行只是示例，不是统计。
