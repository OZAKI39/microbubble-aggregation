## 结论

**一、三种连续变化都能做，片都不断开；能不能"跟上"取决于变化的种类和速度。** 起点都是那张 20 s 的 250 泡片（俯视长约 63 µm、竖着的一层泡），无粘附，9.375 MHz。

| 变化 | 用时 | 结果 |
|---|---|---|
| **平移**：节点面移 20 µm | 1.6 s（12.5 µm/s） | 跟不上：最多落后 6.3 µm，贴面比例掉到 0 |
| | 6.4 s（3.1 µm/s） | 勉强：落后约 1.4 µm（≈ 0.8R），贴面比例最低 0.57 |
| | 25.6 s（0.8 µm/s） | 完全跟上：落后 ≤ 0.7 µm，贴面比例一直 1.00 |
| **直线→波浪线**：弧顶留在片中心 | 1.6 / 6.4 / 25.6 s | 三档都跟上：贴线比例 ≥ 0.97，片和零线弯得一样（弯曲比 1.02–1.03） |
| **线→点**：Y 对按 90° 加入 | 1.6 / 6.4 / 25.6 s | 片沿自身方向收成竖柱：长度降到原来的 0.17–0.26，高度方向拉长 |
| **线→点，中途停**：加到一半后换回平行线 x | 3.2 s，再保持 5 s | 片停在中间长度（0.88），重新平铺在节点面上，5 s 里不变 |

- **三种变化全程都是 1 块；**保持阶段，平移和弯曲都回到线上（贴面/贴线比例 1.00）。
- **平移比转动难跟：**拉回速率约每秒 2–3，只有转动的一半左右（转动是每秒 5.2）。一种可能的解释是平移时整张片的泡都朝同一方向走，而转动时靠中心的泡几乎不动；这里没有单独验证。
- **弯曲最容易跟：**弧顶附近的泡几乎不用动，只有两端各移约 12 µm。
- **线→点没有"中间形状"：**只要 Y 对的份额大于 0，零点就只剩中心那根竖线，片最终都会收成柱；中间形状靠"中途换回平行线 x"来保住（平行线 x 沿面方向没有力，片保持当时的长度）。所以线→点的形状是由"加多久"控制的，而不是由"加多少"控制的。

**二、弱粘附：每对接触 1e-14 到 1e-12 N 不挡住形状变化，1e-11 N 起就挡住了。** 128 泡（预训练初态的最大泡数）的三维团放在通道中心，只开 X 对（上限 6000 Pa-eq），6.4 s：

| 粘附（每对接触） | 3.4 MHz | 6.0 MHz | 9.375 MHz |
|---|---|---|---|
| 0 | 1.00（基准） | 1.00 | 1.00 |
| 1e-14 N | 0.95 | 1.11 | 1.00 |
| 1e-13 N | 1.01 | 1.20 | 1.00 |
| 1e-12 N | 0.63 | 0.95 | 0.68 |
| 1e-11 N | 0.16 | 0.26 | 0.15 |
| 1e-10 N | 0.15 | 0.12 | 0.07 |

表中是"团压向节点面的程度"（垂直于节点面的离散度在 6.4 s 里减小的量）与无粘附时之比。
- 据此把图样运行的弱粘附定为 **1e-14 – 1e-12 N 对数均匀随机**（同日稍后改为所有运行统一用这个范围，并在 64、255 泡上检查了两端，见 `evidence/pretrain_ranges_20261108/`）：从"和没有一样"到"慢约三分之一"，都不挡住形状变化。默认的 5.04e-10 N 比上限大约 500 倍。
- **3.4 MHz 是特殊情况：**无粘附或 ≤ 1e-13 N 时，团先裂成最多 3 块，约 1.1 s 时又快速并回；这期间每步最大位移达到约 1.1R（1 ms 步长）。1e-12 N 时团不裂。
- **步长减半对照（0.5 ms）：**统计量相同（垂直节点面离散度 3.84 → 3.88 µm，贴面比例 0.27 → 0.25，最后都是一整块，0.5 ms 那条有 1 个泡单独算一块），但单个泡的轨迹在这次快速并合之后分开（末了中位相差 3 µm）。这与项目以前在 122 泡初态上看到的情况一样（`fixed_step_s` 的理由）。所以 1 ms 步长按项目已有标准可用，但 3–4 MHz、弱粘附下有这种快速事件，已记为局限。

## 怎么做的

### 第 1 部分：三种连续变化（`MORPH.py.txt`、`MORPH_RUNS.py.txt`）

- **起点：** 与转动测试相同，`L_N250_9.375MHz_lines_x_adh0` 20 s 时的片：100% 在节点面 1R 内；沿 y 16.0 µm、高 15.7 µm（离散度），垂直方向 0。
- **声场：** 每对 PZT 的写法与 `SCULPT.py.txt` 相同（S/2 · e^{i(turn ∓ β − θ)}/|h|，在中心给出 S·e^{i turn}·cos(κs + β)）。
  - **平移：** 只开 X 对，β_x = π/2 − κ_x d，节点面移到 x = d，d 从 0 到 20 µm；推力大小不变，X 两路一直是 6000 Pa-eq。
  - **直线→波浪线：** Y 对同相加入，份额 a_y 从 0 到 0.7；同时 β_x = arccos(−a_y)，让零线始终过片中心、弧顶留在那里；两对一起乘 1/√(1−a_y²)，让中心处的推力大小不变。整个扫描用同一个缩放，最大一路（a_y = 0.7 时的 X 两路）为 6000 Pa-eq，所以开始时 X 两路是 4285 Pa-eq。a_y = 0.7 时就是上一步的"波浪线"图样。
  - **线→点：** 转动测试的驱动，但 Y 对再转 90°（γ 从 0 到 45°）。|p|² 里 cos²γ 那份把泡压在 x = 0 面上，sin²γ 那份把泡沿片推向 y = 0。
- **分段：** 与转动测试相同：第 k 段取目标值 × k/n，最后一段再延长 2 s 作为保持；"中途停"那条是 32 段 × 0.1 s 加到 22.5°，再一段平行线 x 保持 5 s。都在 64 段以内。
- **只在检验进程里改的设定：** 初态、动作、粘附为 0、墙钟上限 6 h。其余全是项目默认（全体耦合带延迟、携带状态的 APECSS、GPU 声场、C++ 接触步）。5 ms 步长，每 25 ms 存一帧；每步最大位移 ≤ 0.40 µm（0.22R）。
- **声场检查（`data/DRIVE_CHECK.json`）：** 用项目的圆片声场直接算：
  - 三种变化在零点处的推力大小全程不变（1.000）；
  - 平移后的节点处 |p| ≤ 最大值的 0.5%（局部波数近似在 20 µm 上的误差，对应约 0.13 µm 的节点偏差；保持阶段剩下的 0.16–0.24 µm "落后"就是它）；
  - 弯曲零线上 |p| ≤ 0.4%；
  - 线→点的终点就是上一步的"点"图样。
- **怎么量（`ANALYSE_MORPH.py.txt`）：** 每一帧和产生它的那段声场比；块数（表面间隙 < 0.5R）；离散度；平移：落后量 = 节点面位置 − 泡的平均 x，贴面比例 = 离节点面 < 1R 的份额；弯曲：到弯曲零线的距离 < 1R 的份额，抛物线 x = x0 − b·y² 拟合片和零线（|y| ≤ 32 µm），两者之比；线→点：离 x = 0 面 < 1R 的份额、沿 y 的离散度（片长）。

### 第 2 部分：弱粘附（`ADHESION_RUNS.py.txt`）

- **起点：** `sculpt.centred_start(128, 1.25, 种子 6)`，通道中心的三维不规则团。
- **驱动：** 只开 X 对（平行线 x），上限 6000 Pa-eq，一段 6.4 s；频率 3.4、6.0、9.375 MHz（X 对在 4、8 MHz 附近到不了中心，避开）。
- **粘附：** 0、1e-14、1e-13、1e-12、1e-11、1e-10 N（每对接触），作用距离用策略的 0.2 µm。
- **步长：** 1 ms（策略默认），每 50 ms 存一帧；3.4 MHz 的无粘附和 1e-13 N 两条另用 0.5 ms 重跑。
- **判据（`ANALYSE_ADHESION.py.txt`）：** 垂直节点面离散度在 6.4 s 里的减小量，与同频率无粘附时之比 ≥ 0.5 算"不挡住"。贴面比例只报告不作判据：3.4 MHz 无粘附时团先裂开再并回，贴面比例几乎不变（0.26 → 0.27），拿它作比没有意义。

## 验证与运行记录

- **服务器：** RTX 4090；项目代码在这两部分运行时与本地一致（开跑前核对了哈希）。12 条并行。

- **第一次启动的失败（如实记录）：** 平移 3 条、线→点中途停 1 条、9.375 MHz 的弱粘附 6 条，开跑时被项目的声源上限检查拒绝（"source limit 0–6000; no clipping"）。原因是缩放复数权重时最大一路比 6000 多出一个舍入误差。改成"幅值和相位分开算、最大一路按 cap × (a / a_max) 恰好等于 6000"后重跑；改动小于 1e-12。直线→波浪线和线→点的 3+3 条用的是改前的 `morph.py`，它们本来就没超过上限，幅值与改后差别小于 1e-12。失败的输出保留在服务器的 `first_attempt_cap_rounding/`。
- **图和动画：** 都看过，与统计一致。

## 局限

- **第 1 部分只在无粘附模型里做；**弱粘附（1e-14–1e-12 N）下三种变化没有重跑。
- **只有一张片（250 泡）、一个频率（9.375 MHz）、一个平移方向和幅度（+x 20 µm）。**
- **平移拉回速率只有转动的一半左右，原因只是推测。**
- **弱粘附的判据是"6.4 s 里压向节点面的程度"，只用一种团（128 泡、一个种子）、一种图样（单对驻波）测；**线→点这类要大量重排的变化，弱粘附的影响可能更大。
- **3–4 MHz、弱粘附下有快速事件，**每步位移可达约 1R（1 ms 步长），轨迹细节随步长变化，统计量不变。
- **全部是离线仿真，**均匀水模型，没有 PDMS；PZT 在这些频率的实际输出未知。
