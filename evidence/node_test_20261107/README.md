# 驻波节点能不能把泡团撕开（2026-11-07，小检验，用户授权，服务器上运行）

> **状态（2026-11-09 核对）：** 历史。用当时的默认粘附 5.04e-10 N 做的检验；2026-11-08 起默认改为弱粘附 1e-14–1e-12 N。

**问题：** PZT 只有 4 个，是不是因此松不开泡团？我之前推算，节点是唯一可能撕开泡团的地方。驻波里声压始终为零的位置叫节点，声压最大的位置叫波腹。节点两侧的泡反相振动、互相推开，主声力又把两半推向各自的波腹。只用一对对面的 PZT 就能把节点放在泡团中心，本次检验这个推算。**项目代码没有改。**

## 结论

**推算不成立：节点没有把泡团撕开。**

1. **默认粘附下完全不动。** 6 个起始团在节点处：
   - 一直是一整块；开头 0.1 s 后几乎没有接触断开（122 泡的那条最多有 2 对）；
   - 被挤得更紧（每泡接触数 2.35–2.64 → 2.70–2.98）；
   - 停在节点上（重心移动 ≤ 0.2 µm），只是整块转动：1.4 s 里转 4–39°，扣除转动后各泡位置的均方根变化 ≤ 0.41 µm。
2. **在节点卡住泡团的是粘附，不是 F2。** 节点处泡几乎不振动：
   - 泡间 F2 的力差比波腹处小 16–87 倍，只有主声力差的 1.5–4.9 倍（波腹处是 39–132 倍）；
   - 粘附力（接触时 5.0e-10 N）按声源幅值设定，不随当地声压变小，是节点处 F2 力差的 50–750 倍。
   - 2026-11-07 的结论“卡住泡团的是 F2”只在声压高的地方成立（单路行波、波腹）。
3. **不加粘附时，只是边上掉下小块。**
   - 50–122 泡的泡团：边上的单个泡、两三个泡一组的小块掉下来，一多半沿通道方向停在 ±123–179 µm，即波腹附近（有的还横向走了几百微米）；
   - 主体（88–95% 的泡）留在节点（±3 µm），内部明显重排：每 0.1 s 每泡断开 0.10–0.47 对接触，形状变化是噪声底的 8–24 倍；
   - 20 泡的泡团曾分成两半（0.42–0.48 s），随后又合上；32 泡的不散。
4. **整团往节点去，单个泡往波腹去。**
   - 从波腹出发的 6 个泡团里，20 泡的那个在 1.5 s 里移到了 146 µm 外的节点；其余留在波腹（对称位置上推力相互抵消，±5 µm）；
   - 掉下来的单个泡则去了波腹。
   - 解释（推测，未直接验证）：团里的泡一起振动，整团的共振频率低于驱动频率，所以像比共振大的泡一样被推向节点；单个 1.78 µm 的泡比共振小，被推向波腹。所以节点处两半不会被往外拉，反而被往节点压。

**对“4 个 PZT 是否太少”：** 4 个 PZT 能做出节点；在节点处，泡间声学吸引确实降了一两个数量级，但泡团还是不散。默认粘附下是粘附把它卡住；不加粘附时整团被推向节点（上面第 4 点，推测），所以只掉边上的泡。这两点都和 PZT 的个数无关。

## 方法（`NODE_RUNS.py.txt`）

- **起始团：** 2026-11-07 soft3d 那 6 个三维随机初态（种子 23/14/21/16/17/7，20/32/50/76/99/122 泡）。
- **驱动：** X− 和 X+ 两路，2.5 MHz，1.5 s。
  - 较强的一路取声源上限 6000 Pa-eq，另一路按比例降到 1266–4416 Pa-eq，使两路在起始团重心处的声压一样大，每路 2.5–8.2 kPa。
  - 相对相位取两种：
    - **节点**：两路在重心处抵消，剩余 ≤ 3e-12 Pa；
    - **波腹**：两路相加，4.9–16.3 kPa。
  - 波腹（或节点）在 ±143–159 µm（图 a）。
- **粘附：** 两种设定都用默认值（×1）；节点另加不加粘附（×0）。
- **其余：** 全部是现在的默认设置。只在运行进程里替换了驱动（`control.random_actions`），并在每次算力后记下力的统计，同 soft3d。
- **分析（`ANALYSE_NODE.py.txt`）：**
  - 块：表面间隙 < 0.5R 的泡算一块；
  - 接触：间隙 < 0.01R；
  - 形状变化：同 soft3d 的俯视指标，用本运行自己的刚体噪声底对照；
  - 转动：每 0.1 s 和整段的刚体最佳拟合（Kabsch）。

## 局限

- 只用了一种频率（2.5 MHz）和 X 方向的一对 PZT，每个起始团只把节点放在重心这一种位置，每条 1.5 s。
- “整团被推向节点”是根据运动方向的推测，没有直接计算整团的集体共振。
- 粘附力的大小是唯象标定的，并按声源幅值的平方设定，不随当地声压变化。真实包膜之间的粘附是不是这样，没有数据。
