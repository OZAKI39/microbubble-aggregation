# 泡大小不一能否让泡团变“硬”：静态诊断（2026-11-03）

**问题：** 预训练档用全体耦合时，仿真泡团比真实泡团软得多。用户的检查是：每挪动 1 px，长宽比的变化约为真实的 40 倍。本诊断检验一个可能的原因：真实 SonoVue 泡大小不一，仿真里却全是 1.78 µm。大小不一时，各泡固有频率错开，可能削弱“整团一起振动、互相压制”，从而让泡之间的吸引恢复。

**结论：不能。** 大小不一反而让团更软，两种耦合模型都是这样。只做诊断，工程代码未改。

## 方法

- **泡团：** 单层（z = 0），向中心收拢，任意两泡表面间隙 ≥ 0.7 µm（同 AG32_local 的平均间隙 0.71 µm）。泡数 N = 32 和 96（真实团面积约为仿真团的 3 倍）。另外直接用存储的 AG32_local 作对照。
- **半径：** 全相同，或对数正态分布（几何标准差 1.15 / 1.3 / 1.5），截断在 0.5–5.5 µm（即 SonoVue 直径 1–11 µm）。中位半径 1.78 µm（仿真值）和 1.25 µm（SonoVue 平均直径 2.5 µm）各算一组。每种 4 个随机样本。
- **单泡响应：** 每个半径用 APECSS 线性响应 χ(R) = V1/P（`CHI_GRID.json`，2.5 MHz，1000 Pa）。包膜参数各尺寸都相同；其随半径的变化未知。在这组参数下，2.5 MHz 的共振半径约为 2.05 µm。
- **声场：** 直接 FNM，1000 Pa-eq（线性区）。两种情形：只开 X+ 一路（团中心在 (300, 150, 0) µm）；X 对（团中心离波腹 20 µm）。
- **耦合模型：**
  - “孤立”：每个泡只响应入射声场，相当于成对模型去掉两泡反馈；
  - “全体”：u = (I + χK)⁻¹χP，带传播延迟。
- **力：** 一律用裸单极公式，不加软核，保证各情形之间可比。
- **指标：**
  - 团内吸引：表面间隙 < 1 µm 的相邻泡对，取吸引力分量的中位数；
  - 拉开团的力：各泡主 Bjerknes 力偏离团平均值的均方根；
  - 两者之比：越大，团越不易被拉开。

## 结果（`POLY_STATIC*.json`，`polydispersity_static.png`；表中为 4 个样本的中位数）

| 情形 | 孤立模型之比 | 全体模型之比 | 全体模型中各泡振幅 / 孤立 |
|---|---|---|---|
| AG32_local，单路 / X 对 | 11701 / 423 | 1.35 / 5.7 | 0.11–0.12 |
| N32 等大 1.78 µm，单路 / X 对 | 8788 / 316 | 2.4 / 22.7 | 0.22 |
| N32 σ 1.15 | 8.8 / 42 | 1.3 / 10.9 | 0.16–0.17 |
| N32 σ 1.3 | 2.7 / 11.3 | 0.49 / 2.1 | 0.17–0.18 |
| N32 σ 1.5 | 1.4 / 4.4 | 0.11 / 0.36 | 0.13 |
| N96 等大，单路 / X 对 | 5294 / 182 | 1.8 / 10.2 | 0.12 |
| N96 σ 1.5 | 0.6 / 1.9 | 0.05 / 0.15 | 0.06 |
| N32 等大 1.25 µm，单路 / X 对 | 约 4600 / 84 | 36 / 59 | 0.95–0.99 |
| N32 中位 1.25 µm，σ 1.5 | 0.2–0.8 / 0.9–2.2 | 0.04–0.5 / 0.15–1.1 | 0.16–0.30 |

1. **AG32_local 的数字与用户的检查吻合：** 振幅约 0.12；两种模型的比值相差约两个数量级（用户的指标是 650 → 2–3）。
2. **大小越不一，团越软，两种模型都是。** 半径大于共振半径（约 2.05 µm）的泡，振动相位与小泡相反，相邻泡对中 13–42% 变成互相排斥。大泡的振动和主力又大得多，团内各泡所受主力差别随之变大。
3. **全体耦合“软”的程度，强烈取决于泡离共振有多近。** 全是 1.78 µm 时（接近共振），团内振动被压到约 0.1–0.2；全是 1.25 µm 时（远离共振）几乎不被压制（0.95–0.99），全体耦合与孤立模型在 X 对下只差约 1.5 倍。
4. 真实泡同样大小不一，却比两种模型都更不容易变形。这说明真实团里还有模型没有的“拢住”机制，例如包膜之间的粘附、贴壁摩擦。用户在 MB_track 里也看到，不开声场时就有静止的微团。
5. 用户实验观察（2026-11-03 口头报告，尚未定量）：超声造成的 SonoVue 团在关掉超声后会在一段时间内保持不散。关掉声场后，所有声学力都消失了，团能保持，说明存在与声无关的保持机制：泡间粘附，或者贴壁粘附。另外，开声时真实团能整体移动且很少变形（用户的“每 px 长宽比变化”指标），而单纯粘在壁上的泡应当被钉住不动，所以至少有一部分是泡与泡之间的凝聚。

## 局限（未运行）

- 静态：只看一个时刻的力，没有模拟运动。用的指标也不是用户的“每 px 长宽比变化”。
- 只做了线性区（1000 Pa）。
- 包膜参数对所有尺寸都相同。文献中包膜粘性在同批泡之间可相差约 10 倍；阻尼更大会削弱共振附近的效应。
- 单层排列，表面间隙固定 0.7 µm，没有近场、平移耦合和包膜接触。
