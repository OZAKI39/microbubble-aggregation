## 结果（`fig_complex_ychip.png`、`data/COMPLEX_ychip.json`）

10 条运行全部 PASS，泡团始终是一块。表中第二列是新芯片（5 ms 步长），括号里是旧芯片同一变换的结果。

| 变换 | Y 形通道芯片（旧芯片） |
|---|---|
| 转半圈 180° | 零线上的比例：变化期间平均 0.47、结束 0.70（0.79、1.0）；长轴滞后最大 9.3°、平均 5.7°（5.0°、1.3°） |
| 绕一端转 60° | 比例在约 11 s 达到峰值 0.6，约 22 s 降到 0（峰值 0.85、结束 0.22）；滞后最大 49°、平均 6.3°；45° 以后零线弯离泡团，泡团停在真实的低声压谷里（`fig_pivot_views_ychip.png`）；没有断开 |
| 一片 → 交叉 → 一片 | 交叉保持结束时比例 0.48（0.74），结束 0.68 |
| 摆动，周期 2 s | 弯曲幅度比 0.52、滞后 0.29 s（0.82、0.18 s） |
| 摆动，周期 8 s | 弯曲幅度比 1.14、滞后 0.41 s（1.20、0.23 s） |

- **对准更晚：** 泡团在 1.7–2.6 s 后才有明确的方向，旧芯片是 0.65–1.25 s。
- **继续变薄：** 变化结束后，零线上的比例仍在上升，泡团继续压成竖直的薄片：宽约 1.5 µm，高 8–13 µm。

**为什么比旧芯片跟得慢：** 每单位源强在参考点产生的声压，新芯片两侧方片是 0.93，旧芯片两侧圆片是 2.0；两端分别是 1.31 和 1.72。
- 新芯片两侧方片离通道 7.2 mm，旧圆片是 4.5 mm，面积也更小；
- 在同一 6000 Pa-eq 上限下，图样处的声压更低。辐射力按声压平方变化，所以推力弱好几倍，泡团变形更慢。

## 步长核查（`fig_step_check_ychip.png`、`data/STEP_CHECK_COMPLEX_YCHIP.json`）

5 ms 与 2.5 ms 比较：
- 零线上的比例：任一时刻相差 0.04–0.11；
- 汇总数字一致，例如转半圈滞后最大 9.3° 对 9.8°，摆动 8 s 幅度比 1.14 对 1.08；
- 同一泡在结束时的均方根距离为 4.4–5.7 µm。这是单个泡的轨迹，集体形状一致；
- 每步最大位移：5 ms 时 0.29–0.41 R，2.5 ms 时 0.15–0.23 R。

结论与旧芯片相同：5 ms 步长的形状和汇总数字可用，单个泡的轨迹不收敛。
