# 粘附力改为与声场无关的定值（2026-11-07，用户决定）

> **状态（2026-11-09 核对）：** 部分过时。“粘附与声场无关、是一个定值”仍然成立；默认值和取值范围 2026-11-08 起改为所有运行统一的弱粘附 1e-14–1e-12 N（`evidence/pretrain_ranges_20261108/`），5.04e-10 N 只作参考。

**改了什么：** 以前一条运行的粘附力 = 1.4e-17 N/(Pa-eq)² × 这条运行最大的单路幅值的平方，跟着声源强度变。现在粘附当作包膜本身的性质，是一个与声场无关的定值：

- 默认值 5.04e-10 N；
- 生成预训练运行时，在 2.7e-10–9.0e-10 N 内对数均匀随机取值；
- 运行配置仍可写 `adhesion_force_N`，写 0 即关闭。

**数值怎么定的：** 默认值和范围就是以前的系数及其标定范围（1.4e-17，7.5e-18–2.5e-17）在声源上限 6000 Pa-eq 下的值，1.4e-17 × 6000² 与 5.04e-10 逐位相同。所以最大单路幅值达到上限的运行，结果完全不变。作用距离 0.2 µm 和力随间隙变化的形状都没有改。

**行为上的变化：**

1. 最大单路幅值 A 低于上限的运行，粘附变为原来的 (6000/A)² 倍。声源越弱，粘附相对声学力越强。
2. 整条运行所有通道都关着时，以前没有粘附，现在有。引入粘附的出发点正是“关掉超声后泡团仍不散”。
3. 一条运行里各段的粘附不再取决于别的段。以前取全程最大的单路幅值，后面某段开得强，前面各段的粘附也跟着变大，等于后面的动作影响前面的动态。

## 改动的文件

| 文件 | 改动 |
|---|---|
| `configs/pretrain_policy.json` | `adhesion`：`coefficient_N_per_Pa2`、`coefficient_range_N_per_Pa2` 换成 `force_N`、`force_range_N`；`use` 和 `reasons.adhesion` 的说明 |
| `workflows/f10ag.py` | `contact_terms(cfg, policy)`：不再读 `adhesion_reference_Pa_eq`、`adhesion_coefficient_N_per_Pa2`，也不再需要各段幅值（参数 `segments` 去掉）；task 里不再记这两项 |
| `tests/test_pretrain.py` | 粘附的两项测试改为检查定值，并检查默认值等于以前在上限下的值 |
| `README.md`、`docs/MODEL_AND_CALLFLOW.md` | 粘附的说明 |

旧配置里如果还写着 `adhesion_coefficient_N_per_Pa2` 或 `adhesion_reference_Pa_eq`，现在不再起作用，以前删掉的配置项也是这样处理的。仓库里的配置都没有这两项；`evidence/` 里旧检验的配置副本有，那是历史记录。

## 验证

- **测试：**
  - 服务器 50/50 通过；
  - 笔记本 49/50 通过。失败的一项仍是不规则泡团初态的逐位复现：服务器（AVX-512）生成的文件与笔记本重新生成的差最大 1.2e-20 m，与本次无关。
- **开到上限的运行不变（`CAP_CHECK.py.txt`，`data/CAP_CHECK.json`，服务器）：** 用改动后的代码、默认粘附，重跑驻波检验里的两条运行。它们较强的一路正好是 6000 Pa-eq：20 泡和 122 泡，节点在团中心，1.5 s。
  - 两条的粘附力都是 5.04e-10 N，与以前相同；
  - 每 1 ms 存下的 1501 帧位置与原运行**逐位相同**（最大差 0 m）。
- **普通随机动作运行变化多少（`FIGURE_SCRIPT.py.txt`，`data/RATIOS.json`）：** 用默认随机动作（种子 0–1999）生成动作序列，比较每条运行新旧两种粘附：

| 运行长度 | 新 / 旧，中位 | 新 / 旧，90% 分位 | 变化在 10% 以内的运行 | 全部通道关闭（以前无粘附） |
|---|---|---|---|---|
| 0.1 s（1 段） | 1.96 | 16.5 | 8.9% | 6.7% |
| 0.3 s（3 段） | 1.27 | 2.40 | 24% | 0.05% |
| 1 s（10 段） | 1.07 | 1.26 | 60% | 0 |
| 3 s（30 段） | 1.02 | 1.08 | 94% | 0 |
| 6.4 s（64 段） | 1.01 | 1.04 | 99.8% | 0 |

  运行越长，全程最大的单路幅值越接近上限，变化越小。短运行和低幅值的运行变化大。

## 未做

- 没有重跑以前的检验（soft3d、驻波节点等）。它们的声源都开到了上限，粘附没有变。
- 粘附力的大小仍是唯象标定的。它当时按“粘附 ÷ 声源强度²”定比值，现在取的是这个比值在上限下的值；在更弱的驱动下泡团的软硬会和以前不同，没有和真实录像比较过。
