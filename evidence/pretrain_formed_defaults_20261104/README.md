## 2. 实验式方案与随机动作（`FINAL_COMPARISON.json`，`final_comparison.png`）

- **实验式方案：** 你分支的三段方案（X− → Y− → X−，各 1.5 s），每路改为 3000 Pa-eq，在正式上限之内。32 泡跑中心、偏心各一条，128 泡只跑中心一条。
- **随机动作：** 你分支的 4 条随机动作配置（每 0.1 s 换动作，2 s），只把初态换成 `FORMED_N32_a1.0_s1`。
- 7 条全部 PASS。

| | 每 px 形状变化（中位） | 每 0.1 s 形状变化 | 长宽比 中位 / p90 | 分裂 | 刚开启 0.5 s 团速 → 1 s 后 |
|---|---|---|---|---|---|
| 真实 A/B（开 PZT） | 0.0018 | 0.026 | 1.12 / 1.30 | 很少 | 140 → 16 px/s |
| 旧：全体耦合，实验式 | 0.076 | 0.097 | 1.81 / 2.16 | 44% | 16 → 17 |
| 旧：成对模型，实验式 | 0.0004 | 0.011 | 1.12 / 1.16 | 0 | 317 → 330 |
| 旧：全体耦合，随机动作 | 0.056 | 0.153 | 1.64 / 2.26 | 39% | 20 |
| **新：32 泡，实验式** | **0.0013** | 0.0039 | **1.12 / 1.13** | **0** | 43 → 43 |
| **新：128 泡，实验式** | **0.0013** | 0.0013 | 1.03 / 1.03 | 0 | 13 → 13 |
| **新：32 泡，随机动作** | 0.009 | 0.013 | 1.15 / 1.45 | 0 | 13 |

1. **实验式方案下，新默认设置的“每 px 形状变化”和长宽比都与真实相符**，也不再碎开。旧的全体耦合约为真实的 40 倍，旧的成对模型约为 1/4。
2. **“每 0.1 s 形状变化”比真实小**（0.004 对 0.026），原因是团走得慢：真实刚开启时约 140 px/s，仿真 43 px/s。每 px 的变化相同，每个窗口走的距离少，形状变化也就少。除粘附外，所有力都与 A² 成正比，粘附也按 A_ref² 设定，所以换增益只改快慢、不改形状。
   - 要让 32 泡团达到真实团速，需约 5400 Pa-eq；128 泡团更慢，需要更高。这超过了现在的上限 3000。
   - 是否提高上限要你决定。提高要改 `configs/pretrain_policy.json`，并新建准入记录。
3. **随机动作（多路组合、每 0.1 s 切换）的形状变化比实验式大**：每 px 0.0037–0.013，长宽比 p90 1.45。但仍比旧设置小 6 倍，而且不碎。真实数据只有单路持续开启，没有随机动作可以直接对照。
4. **仍然不符：真实团开启后 0.3–1 s 就慢下来，仿真一直匀速。** 真实团大多贴壁（见分支的 `evidence/ab_reference_20261103/`），仿真里没有壁。这就是“贴壁模型”要解决的问题，留到下一步。
5. **耗时：** 实验式 4.5 s 的运行，32 泡用 100–105 s，128 泡用 462 s。随机动作 2 s 的运行用 317–2080 s，频繁切换方向时团内调整多，步数更多。
