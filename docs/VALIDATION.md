## 差异解释与限制

正式科研固定ID界限仍是 **50 nm**；核心旧/新算式回归另用更严格的浮点比较（通常相对2e−12，必要的极小绝对项单独记录），不是放宽正式门限。GPU泡对原子累加顺序和模块编译布局允许末位差异；失败状态重算最大位置差约1.7e−21 m，LF回退位置约8.5e−22 m。所有原Gate判定相同，原密集团失败继续失败。

旧LF参考脚本仅把旧函数的输入、输出与context变为显式参数，循环来自冻结旧 `slow.py`，声力/接触使用旧 `WaterAccelerated`。脚本作为 `.py.txt` 保存，不是新运行依赖。没有修改旧模块全局变量。构造旧低压扩展时显式使用已核验的本地低压表，原 query 和区间拼接算式保持不变；详见 `REFERENCE_RECIPE.json`。

最终114项回归本次记录墙钟约 **3.342 s**（缓存已编译，和其他短验证共享本机资源）；新22项测试日志记录3.43 s。初次编译较慢，早期日志保留，不能把编译耗时或并行共享运行当作独占性能指标。

重构过程中发现过遗漏 `leggauss` 导入、参考脚本缺少 YAML/sha 等工程问题，均已修复。相关失败日志保留在 `evidence/migration/`，不是科学模型失败。原科学失败则在 `evidence/f10ag/` 和新的失败重放中保持原判据。

全部数值证据位于 `evidence/migration/`（上表未写完整前缀）。新执行原始文件位于 `results/`。没有因这些短时PASS修改原 FINAL_GATE、150 ms细化范围或250 ms完成范围。

- **绕一端转 60°：做不到。** 约 45° 后零线本身在离转轴约 50 µm 处与另一组零线重新连接（鞍点），泡团被拉成弯的"7"字形。5 ms 下仍是一整块，2.5 ms 下 30.3 s 断出 30 个泡。

**步长对照：** 两种步长的汇总量一致，例如滞后 5.0° 对 5.1°、交叉处 0.74 对 0.75、摆动幅度比 0.82 对 0.76 和 1.20 对 1.20。同一个泡结束时的位置相差 6.5–10.7 µm，但按整团比较只差 1.4–1.9 µm：形状可用，单个泡的轨迹不收敛。

第一次启动步长对照时把 0.0025 写进了存帧间隔那一列，发现后按进程号停掉、改正重跑（半途的输出保留为失败记录）。同样路径从竖片出发的运行已于 2026-11-09 按用户要求删除。见 `evidence/complex_ball_20261109/`。

## 频率范围放宽到 0.5 MHz；Y 形芯片上的低频仿真（2026-11-09，用户决定，服务器上运行）

**改动：** `frequency_range_Hz` 从 2–10 MHz 放宽到 0.5–10 MHz，随机动作仍为 2–3 MHz。方片 48 个积分点在 0.5–2 MHz 下与 768 点相差 ≤ 7.8e-13，范围测试已更新。

**检验条件：**
- 250 泡球团，中心在参考点；6 种动作（单个 PZT、两端一对、两侧一对，后两种各有"中心声压最强"和"中心声压为零"），0.5 / 0.75 / 1.0 / 1.5 / 2.0 MHz，6000 Pa-eq，每条 1 s。
- 步长 0.1 ms：本地预试中 5 ms 时 2 MHz 下每步移动达 11R。
- 另以 0.05 ms 跑前 0.2 s 核查步长，共 60 条。
- 最初有 4 条因驱动取整（最大一路比 6000 多一个舍入误差）开跑即被拒，改正后补跑，日志保留在 `results/lowfreq_20261109/logs/failed_cap_rounding/`。

**结果：**
- **0.5–0.75 MHz（两种步长一致，同一泡相差 ≤ 1.9 µm）：**
  - 单个 PZT 使泡团整体平移，不变形（0.5 MHz 130–200 µm/s，0.75 MHz 15–21 µm/s）；
  - 一对 PZT 在中心声压最强时泡团不动；
  - 中心声压为零时，泡团沿这一对的方向一分为二、向两侧分开。驱动频率低于泡的共振，泡被推向声压高处。
- **1.0 MHz 最剧烈：** 0.03–0.14 s 内爆开碰壁。这个频率下方片在参考点的声压最高。
- **1.5–2 MHz：** 泡团碎成几块。
- **1–2 MHz 的步长：** 单个 PZT 和爆开的情形在 0.1 ms 下不收敛（同一泡相差 13–41 µm），只能定性。
- 很多条停在碰壁保护处（模型没有壁面作用力）。

**局限：** 均匀水自由场，没有 PDMS 吸收和反射、壁面作用力、声流；驱动强度未标定。见 `evidence/lowfreq_20261109/`。
